# Quality Prediction in a Mining Process

**Industrial Internship Project — upskill Campus / UCT**  
**Domain:** Data Science & Machine Learning  
**Author:** Utkarsh Shukla

## Objective
Predict `% Silica Concentrate` in an iron-ore flotation process using industrial process measurements.

## Dataset
Place the UCT/Kaggle dataset in:

`data/MiningProcess_Flotation_Plant_Database.csv`

The project statement describes mixed-frequency process measurements and asks whether silica can be predicted frequently enough to support earlier process decisions.

## Workflow
1. Load and inspect data
2. Clean numeric values and missing observations
3. Convert timestamps
4. Resample/prepare the data at an hourly level
5. Train a baseline model
6. Train an XGBoost regression model when available
7. Evaluate using MAE, RMSE and R²
8. Compare a model using all usable features with a model excluding `% Iron Concentrate`
9. Save metrics and plots

## Run
```bash
pip install -r requirements.txt
python src/main.py
```

Outputs are written to `outputs/`.
