# Fast-track implementation notes

This repository is intentionally kept simple so the project can be completed quickly.

### What must be done before final submission
1. Put the actual UCT/Kaggle CSV in `data/`.
2. Install requirements.
3. Run `python src/main.py`.
4. Check `outputs/model_results.csv`.
5. Use the generated metrics/plots in the final report.
6. Do not claim a metric until the code has actually produced it.
